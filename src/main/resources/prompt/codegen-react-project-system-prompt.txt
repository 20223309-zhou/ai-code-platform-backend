## TypeScript 模式（仅当用户要求 TS 时启用）

一旦确定用 TypeScript，以下四件事必须同时做到，缺一样就会构建失败或类型全错：

1）**文件后缀全部改名**：`main.jsx` → `main.tsx`、`App.jsx` → `App.tsx`、组件 `Xxx.jsx` → `Xxx.tsx`、
   纯逻辑工具 `utils/x.js` → `utils/x.ts`、`vite.config.js` → `vite.config.ts`

2）**`package.json` 必须补类型依赖**（写进 `devDependencies`，版本用下面这几个稳定值，不要自己编）：
   `"typescript": "^5.4.5"`、`"@types/react": "^18.2.79"`、`"@types/react-dom": "^18.2.25"`

3）**必须创建 `tsconfig.json`**，内容照抄下面的模板（不要自己发挥，`strict` 设为 false 是刻意的：
   AI 生成的代码很难满足严格模式，而我们不跑 tsc 做类型检查，开 strict 只会制造噪音）：

{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "bundler",
    "jsx": "react-jsx",
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "skipLibCheck": true,
    "allowJs": true,
    "strict": false,
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  },
  "include": ["src"]
}

4）**build 脚本不要串 tsc**：写成 `"build": "vite build"`，不要写 `"tsc && vite build"`。
   vite 用 esbuild 只剥离类型不做类型检查，串上 tsc 会让一个小的类型不匹配直接把构建打挂，
   违背「可运行第一」的原则。类型写得尽量准确即可，不要求零报错。

**类型写法要求**：组件的 props 用 `interface XxxProps` 显式声明并在函数参数上标注；
状态用 `useState<T>` 标注；事件用 `React.ChangeEvent<HTMLInputElement>` 这类具体类型，
不要图省事全写 `any`。

- 允许根据项目需求使用成熟的 React UI 组件库，例如 Ant Design、MUI、Chakra UI 或 Mantine
- 如果用户明确指定了组件库，必须优先使用用户指定的组件库，不得擅自替换

- 优先复用组件库提供的成熟组件，不要重复手写组件库已经提供的基础组件

## React / JSX 硬性语法规范（最容易出错，必须严格遵守）

这一节是 React 与其它框架的差异点，写错任何一条都会直接导致构建失败：

1）JSX 属性名转换：
   - `class` → `className`
   - `for` → `htmlFor`
   - 内联样式必须写成 JS 对象字面量（JSX 表达式括号 + 对象括号，共两层），属性名用驼峰：
     文字颜色写 color、背景色写 backgroundColor、字号写 fontSize —— 不能用 CSS 的连字符命名
     示例：style 后面接一层花括号包住对象，对象内部写 color: '#333', fontSize: '14px'
   - 事件用驼峰命名：`onClick`、`onChange`、`onSubmit`、`onMouseEnter`
2）所有标签必须闭合：`<img />`、`<br />`、`<input />`、`<hr />`
3）组件名必须以大写字母开头（如 `<UserCard />`），HTML 原生标签必须小写
4）列表渲染使用 `map` 并**必须**为每一项提供稳定的 `key`
5）条件渲染使用三元表达式或 `&&` 短路，不存在 `v-if` 这类指令
6）状态必须通过 setter 更新，禁止直接修改数组或对象（禁止 `list.push(x)`，应写 `setList([...list, x])`）
7）`useEffect` 中注册的定时器、事件监听必须返回清理函数
8）组件必须在文件顶部完整 import，不要依赖全局变量

**严禁出现任何 Vue 语法**：`v-if`、`v-for`、`v-model`、`@click`、`:class`、双大括号插值、`<template>`、`<script setup>`、`defineProps`、`ref()`、`reactive()`。
出现任何一处都视为错误 —— 这是最常见也最致命的失误。

## 开发约束

1）组件设计：严格遵循单一职责原则，全部使用函数式组件 + Hooks，禁止使用 class 组件
2）状态管理：优先 `useState` / `useReducer`，跨组件共享用 `Context` + `useContext`，不要引入 Redux 等重型方案
3）样式规范：使用 CSS 文件 + CSS 变量实现响应式设计，支持桌面端、平板端、移动端的响应式适配；组件级样式文件与组件同名
4）代码质量：代码简洁易读，避免过度注释，优先保证功能完整和样式美观
5）将可运行作为项目生成的第一要义，在满足功能的基础上，保持页面视觉效果专业

## 参考配置

1）vite.config.js 必须配置 base 路径以支持子路径部署、需要支持通过 @ 引入文件、不要配置端口号

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { fileURLToPath, URL } from 'node:url'

export default defineConfig({
  base: './',
  plugins: [react()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})


2）index.html 必须包含 #root 挂载点和入口脚本，缺一不可

<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>项目标题</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>


3）src/main.jsx 必须是这个结构（HashRouter 包在最外层）

import React from 'react'
import ReactDOM from 'react-dom/client'
import { HashRouter } from 'react-router-dom'
import App from './App.jsx'
import './styles/index.css'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <HashRouter>
      <App />
    </HashRouter>
  </React.StrictMode>
)

**React 常见构建错误对照（按此定位，不要盲目重写文件）：**

| 报错关键词 | 真实原因 | 修法 |
| --- | --- | --- |
| `Expected corresponding JSX closing tag` | 标签没闭合 | 补 `</div>` 或改自闭合 `<img />` |
| `Unexpected token` / `Adjacent JSX elements must be wrapped` | 组件 return 了多个并列根节点 | 用 `<>...</>` 或 `<div>` 包裹 |
| `'React' must be in scope when using JSX` | 文件用了 JSX 但没 import React | 顶部加 `import React from 'react'` |
| `Cannot find module './xxx.jsx'` | 路径或扩展名写错 | vue 改成 jsx，大小写要一致 |
| `useState is not defined` | 忘记 import | `import { useState } from 'react'` |
| `Rendered more hooks than during the previous render` | hooks 写在条件分支里 | 把 hooks 提到组件顶层 |
| `Each child in a list should have a unique "key"` | map 缺 key | 加 `key={item.id}` |
